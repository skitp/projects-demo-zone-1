Option 1 (Recommended): Separate Feedback Fact
FactClaimFeedback

Grain

One row per feedback submission.

This is the cleanest design because a claim can potentially receive:

multiple feedback events
post-chat surveys
post-claim surveys
NPS surveys
follow-up surveys

without altering the FNOL fact grain.

Table Structure
CREATE TABLE claims.FactClaimFeedback
(
    ClaimFeedbackKey      BIGINT         NOT NULL,
    ClaimFNOLKey          BIGINT         NOT NULL,
    ClaimReference        VARCHAR(50)    NOT NULL,

    FeedbackDateKey       INT            NOT NULL,

    LineOfBusinessKey     INT            NOT NULL,

    SkippedToFormFlag     BIT            NOT NULL,

    RatingScore           TINYINT        NULL,

    FeedbackComment       VARCHAR(4000)  NULL,

    FeedbackCount         INT            NOT NULL,

    SubmittedAtUTC        DATETIME2(6)   NOT NULL,

    SourceRecordHash      BINARY(32)     NULL,

    RecordCreatedUTC      DATETIME2(6)   NOT NULL
);

Useful Measures
Claims Submitted
Claims Submitted =
SUM ( FactClaimFNOL[ClaimCount] )

Feedback Responses
Feedback Responses =
SUM ( FactClaimFeedback[FeedbackCount] )

Average Rating
Average Rating =
AVERAGE ( FactClaimFeedback[RatingScore] )

Form Skip %
Form Skip % =
DIVIDE(
    CALCULATE(
        COUNTROWS(FactClaimFeedback),
        FactClaimFeedback[SkippedToFormFlag] = TRUE()
    ),
    COUNTROWS(FactClaimFeedback)
)

Response Rate
Response Rate % =
DIVIDE(
    COUNTROWS(FactClaimFeedback),
    COUNTROWS(FactClaimFNOL)
)

Final Recommendation

Keep the existing model unchanged and add:

FactClaimFeedback (new fact table)
Optionally DimFeedbackRating
AuditFeedbackPayload for lineage

The resulting dimensional model contains two related fact tables:

FactClaimFNOL → claim intake event
FactClaimFeedback → customer feedback event

linked through the common claim (ClaimFNOLKey / ClaimReference).

This preserves proper grain, supports multiple feedback submissions per claim in the future, and enables FNOL experience analytics without polluting the claim fact with survey-specific attributes.
